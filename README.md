## About

I build interfaces with React and Next.js, using TypeScript to keep the codebase predictable as it grows. I care more about how a project holds up six months after launch than how fast it ships — clear component boundaries, typed data flow, and consistent naming save time later, even if they cost a bit more upfront.

Working as a frontend developer, focused on writing code that's easy for someone else — or future me — to pick up without a walkthrough.
